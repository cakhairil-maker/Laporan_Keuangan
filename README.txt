PAKET PWA LAPORAN KEUANGAN

Isi folder:
- index.html              aplikasi utama
- manifest.json           metadata PWA
- sw.js                   cache/offline
- icons/                   ikon aplikasi iPhone/Android

CARA PAKAI DI IPHONE
1. Upload SEMUA isi folder ini ke hosting HTTPS dalam folder yang sama.
2. Buka alamat index.html memakai Safari di iPhone.
3. Tekan tombol Share.
4. Pilih Add to Home Screen / Tambahkan ke Layar Utama.
5. Buka aplikasi dari ikon di Home Screen.

PENTING
- Data transaksi tersimpan di localStorage browser/PWA pada perangkat tersebut.
- Menghapus data situs Safari, mengganti domain, atau menggunakan perangkat lain tidak otomatis memindahkan data.
- Jangan hanya upload index.html; manifest.json, sw.js, dan folder icons juga diperlukan untuk PWA/offline.


VERSI 2:
- Backup/restore JSON.
- Rincian setiap pemasukan dan pengeluaran.
- Perbaikan tombol jenis di iPhone.
